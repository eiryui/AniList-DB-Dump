Every release includes

.dump

pg_dump custom format. Best for pg_restore.

.tar

pg_dump tar format, a second copy a moment later.

.sql.gz

Plain SQL, compressed. Works with psql.

.sql.zip

Plain SQL, zipped. Same content as .sql.gz.

-schema.sql

Tables and indexes only, no data.

-csv.zip

One CSV per table. Opens in spreadsheets and pandas.

-json.zip

One JSON Lines file per table. Data only.
